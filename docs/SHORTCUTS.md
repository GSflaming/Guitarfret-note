# 快捷键与设备操作

页面通过浏览器提供的系统信息自动选择按键提示，不请求额外权限，也不上传识别结果。支持 Windows、macOS 及移动设备／通用回退。工具菜单下方「快捷键」入口会显示当前系统；检测错误时可选 Windows 或 macOS，选回「自动识别系统」恢复检测。选择仅保存在当前浏览器。

| 操作 | Windows | macOS | 生效条件 |
| --- | --- | --- | --- |
| 展开／收起工具 | C | C | 非输入状态 |
| 同时弹响所选音符 | Space | Space | 非输入状态，焦点不在按钮或链接上 |
| 播放琶音 | A | A | 非输入状态 |
| 进入／退出录屏模式 | P | P | 非输入状态 |
| 复位整个指板的大小与位置 | 0 | 0 | 非输入状态 |
| 打开快捷键表 | ? | ? | 非输入状态；常见键盘为 Shift + / |
| 移动弦／品焦点 | ↑ ↓ ← → | ↑ ↓ ← → | 先点击指板，或 Tab 聚焦指板 |
| 选中／取消焦点处音符 | Enter | Return ↩ | 指板聚焦时 |
| 移动圆形工具焦点 | 方向键 | 方向键 | 工具菜单聚焦时 |
| 首个／最后圆形工具 | Home / End | Home / End | 工具菜单聚焦时；无独立键时用方向键或 Tab |
| 移动控件焦点 | Tab / Shift + Tab | Tab / Shift + Tab | Mac 浏览器可能需要开启键盘导航 |
| 收起工具／停止播放／退出录屏／清空 | Esc | Esc ⎋ | 按当前状态处理 |
| 鼠标缩放指板 | Ctrl + 滚轮 | ⌘ + 滚轮 | 指针位于画布上 |
| 鼠标平移 | 拖动或滚轮 | 拖动或滚轮 | 指针位于画布上 |
| 触摸板／触屏 | 双指平移、捏合缩放 | 双指平移、捏合缩放 | 在画布上操作 |

Esc 优先关闭打开的工具或设置，然后停止播放、退出录屏模式，最后清空选音；输入框不会触发全局清空。原生对话框使用浏览器自己的 Esc 关闭行为。

字母快捷键不加 Ctrl／⌘／Alt。Ctrl+A／⌘A、Ctrl+C／⌘C、Ctrl+P／⌘P 等系统或浏览器操作保留原有行为；输入法组合输入及长按动作键不重复触发。指板方向键允许长按移动。

缩放也接受 Ctrl 或 Alt 作为兼容修饰键。自动提示只展示当前系统最常用的一种。触屏设备无需物理键盘，所有主要功能都可从工具菜单进入。
