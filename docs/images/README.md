# 文档图片

四张 PNG 直接由当前 `dist/` 界面离屏渲染生成，未修改生产页面；演示为标准调弦的 C 大三和弦，以及深色主题下的 Drop D 空弦 D5。截图使用独立临时浏览器配置和固定示例，不读取使用者已有场景。

`shortcuts.svg` 与 `shortcuts.en.svg` 是中英文快捷键说明图，按键数据直接读取 `dist/shortcuts.mjs`，并非额外设计的应用界面。

安装 Chrome 后，在仓库根目录运行：

```sh
node scripts/capture-docs.mjs
```

脚本自动寻找常见平台的 Chrome 路径，也可通过 `CHROME_BIN` 指定浏览器可执行文件。截图过程使用临时开发预览，完成后关闭并删除临时浏览器配置；不需要 AI 服务或付费调用。

更新界面后请重新生成相关图片，检查文字可读性与显示内容是否符合说明。README 的中英文版本共用四张界面截图，分别引用相应语言的快捷键图。
