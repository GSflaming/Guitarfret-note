# Shortcuts and input

[简体中文](SHORTCUTS.md) · **English**

The shortcut guide uses browser-provided system hints locally, with no additional permission or upload. Windows and macOS have tailored labels; mobile and unknown systems have fallbacks. In **Tools → Shortcuts**, choose Windows or macOS if detection is incorrect, or return to automatic detection. Interface language is a separate setting in **Tools → Language**.

| Action | Windows | macOS | Context |
| --- | --- | --- | --- |
| Expand / collapse tools | C | C | Outside text input |
| Play notes together | Space | Space | Outside text input, buttons, and links |
| Play arpeggio | A | A | Outside text input |
| Enter / leave recording mode | P | P | Outside text input |
| Reset size and position | 0 | 0 | Outside text input |
| Shortcut guide | ? | ? | Usually Shift + / |
| Move string / fret focus | Arrow keys | Arrow keys | Fretboard focused |
| Select / deselect a note | Enter | Return | Fretboard focused |
| Move circular tool focus | Arrow keys | Arrow keys | Tool menu focused |
| First / last circular tool | Home / End | Home / End | Use arrows or Tab if these keys are unavailable |
| Move control focus | Tab / Shift + Tab | Tab / Shift + Tab | Browser keyboard-navigation settings may apply |
| Close / stop / leave / clear | Esc | Esc | Follows the current context |
| Mouse zoom | Ctrl + scroll wheel | ⌘ + scroll wheel | Pointer over the canvas |
| Pan | Drag or scroll | Drag or scroll | Pointer over the canvas |
| Trackpad / touch | Two-finger pan, pinch to zoom | Two-finger pan, pinch to zoom | On the canvas |

Esc closes open tools first, then stops playback, leaves recording mode, or clears notes. Global clearing does not run while typing. Native dialogs use their own Esc behavior.

Press letter keys without Ctrl, ⌘, or Alt. System combinations such as Ctrl+A/⌘A, Ctrl+C/⌘C, and Ctrl+P/⌘P retain their native behavior. IME composition and held action keys do not repeatedly trigger actions; fretboard arrow keys support holding to move.

Zoom also accepts Ctrl or Alt for compatibility. The guide displays the usual modifier for your selected system. GIF demonstrations are silent; recording mode hides tools but does not capture video.
